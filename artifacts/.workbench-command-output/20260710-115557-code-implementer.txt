# Implementation Notes: Default GUI Visual Polish Pass

## Changed

- Tuned the built-in dark and light theme defaults in `python/dragongui/theme.py`.
  - Dark theme now uses a more neutral slate palette instead of the older purple-blue surface stack.
  - Accent remains blue, but neutral background/surface/border tokens carry more of the interface.
  - Default radius changed from `6.0` to `4.0`; default spacing changed from `8.0` to `6.0`.
  - Light theme radius/spacing were kept in parity and its accent/border/muted tokens were slightly tightened.
- Matched native theme defaults in `native/src/theme.rs`.
  - Native dark tokens now match the Python-facing `Theme.dark()` defaults.
  - Native `control_height()` now uses the tighter spacing formula and resolves to `28px` for the default 14px font.
  - Added `dark_theme_defaults_are_compact_and_neutral`.
- Tightened default framework CSS in `native/src/framework.dg.css`.
  - Base radius is now `4px`.
  - Buttons, small buttons, icon buttons, inputs, text areas, code/log views, splitters, nav items, tabs, menu items, and table parts have more compact default padding/metrics.
  - Hover states use calmer `accent_mix_12`/`accent_mix_20` treatments instead of turning many borders fully accent-colored.
  - Text/code/log inputs now explicitly use the neutral `surface` fill and 13px monospace defaults for code/log surfaces.
  - DataFrameTable defaults now include `table-header-height: 26px`, `table-row-height: 23px`, and styled header/row/selected parts.
  - Supported scrollbar parts for `Panel` and `DataFrameTable` now default to transparent tracks and compact rounded thumbs.
- Tightened native metric constants in `native/src/style.rs`.
  - Checkbox, toggle switch, slider, number stepper, tab gap/insets, and active tab bar constants are slightly smaller and more workbench-like.
- Tightened native layout/table metrics.
  - `native/src/layout.rs` now uses the same compact control-height formula as `Theme::control_height()`.
  - `native/src/table.rs` defaults are denser: `28px` header, `23px` rows, `56px` index column, and `128px` data columns.
  - Added `default_metrics_are_compact_for_dense_data`.
- Rebuilt and copied the native Python extension with the available Python 3.12 toolchain:
  - `native/target/release/_dragongui.dll`
  - `python/dragongui/_dragongui.pyd`
- Reran the focused visual audit targets from `artifacts/SPEC.md`, updating `artifacts/visual_audit/REPORT.md`, `report.json`, screenshots, snapshots, and logs.
