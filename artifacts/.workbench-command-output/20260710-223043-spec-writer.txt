+- `examples/all_features_professional_demo.py` uses `dg.Pane(size=0.62)`, `dg.Pane(size=0.38)`, `dg.Pane(size=0.72)`, `dg.Pane(size=0.28)`, `dg.Pane(size=0.7)`, and `dg.Pane(size=0.3)`.

 ## Edge Cases
 
-- Long headings in narrow AppShell bodies.
-- Summary cards with short labels but long descriptions.
-- Three or more cards in a row at `390x720`.
-- Sidebar plus content plus status bar on mobile/narrow widths.
-- Long nav item labels, tab labels, badges, menu labels, table headers, property names, and toolbar button labels.
-- Nested scroll areas inside panels.
-- Mixed fixed/flexible children in `HLayout`, `VLayout`, `FlowLayout`, and grid layouts.
-- Text wrapped to multiple lines inside fixed-height widgets.
-- High DPI rounding on 1px borders, baselines, and scrollbars.
-- Disabled/selected/focused/open/hover states after visual-system changes.
-- Light theme parity for token changes.
+- Numeric pane sizes below `1`.
+- Fixed pixel pane sizes such as `240`.
+- Existing `fr` splitter sizes.
+- Live `Splitter.set_sizes(...)`.
+- Pane `min_size` larger than proportional allocation.
+- Pane `max_size` smaller than proportional allocation.
+- Horizontal and vertical splitters.
+- Nested splitters.
+- Splitters inside scrollable pages.
+- Splitters inside panels.
+- DataFrameTable inside a resized pane.
+- PropertyGrid editors inside a resized pane.
+- Plot widgets inside resized panes.
+- Global Python 3.13 importing stale installed package or stale native extension.
